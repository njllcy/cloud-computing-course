# Cloud Computing Concepts Reflection
Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud technology. Three cloud services that I regularly use are **GCash**, **Facebook**, and **Shopee**. These platforms allow me to perform different tasks conveniently without installing or managing complex software on my device.
GCash is an example of **Software as a Service (SaaS)** because it provides online financial services through a mobile application. Its deployment model is **Public Cloud** since it is available to millions of users over the internet. Facebook is also classified as **SaaS** because it offers social networking services that users can access through a web browser or mobile app. Like GCash, Facebook uses a **Public Cloud** deployment model because it serves a large number of users worldwide. Shopee is another example of **SaaS** since it provides an online shopping platform where buyers and sellers can access its services through the internet. It also uses a **Public Cloud** deployment model because it is accessible to the general public and supports millions of users.
Version control is important when working on cloud projects because it helps organize changes made to files and configurations. Without version control, it would be difficult to identify mistakes, restore previous versions, or collaborate effectively with other team members.
